# 🐾 MichiLandia - El Club Felino

¡Bienvenido a **MichiLandia**! Una landing page interactiva, moderna y cálida diseñada para los amantes de los gatos.

🌐 **Sitio Web En Vivo:** [https://gaspar-rosales.github.io/michilandia/](https://gaspar-rosales.github.io/michilandia/)

![Preview](https://images.unsplash.com/photo-1514888286974-6c03e2ca1dba?auto=format&fit=crop&w=1200&q=80)

---

## ✨ Características Principales

- 🎧 **Estación de Ronron-Terapia:** Sintetizador de ronroneo en tiempo real usando **Web Audio API** (totalmente offline, sin archivos de audio externos) con selector de intensidad (Michi gordito, Gatito bebé, Turbo) y volumen regulable.
- 🗣️ **Michi-Traductor Humano ➔ Gato:** Escribe cualquier mensaje y tradúcelo a dialecto felino con estados de ánimo cambiantes y sonido de maullido sintetizado.
- 🏡 **Galería de Michis en Adopción:** Tarjetas interactivas con filtros por categoría (*Juguetones, Tranquilos, Cachorros*), contador de "amores" y modal de postulación de adopción.
- 🔮 **Generador de Michi-Datos:** Colección de curiosidades científicas sobre gatos con transiciones fluidas y botón para copiar al portapapeles.
- 💬 **Testimonios & Newsletter:** Reseñas de cat-parents y formulario de boletín con toasts interactivos.
- 📱 **Diseño 100% Responsive:** Adaptado perfectamente a móviles, tablets y escritorios usando Tailwind CSS.

## 🚀 Cómo ejecutarlo en local

Puedes visualizar el proyecto directamente clonando el repositorio o abriendo el archivo:

### Opción 1: Abrir directamente
Abre `index.html` en tu navegador favorito.

### Opción 2: Con servidor local de Python
```bash
python3 -m http.server 8000
```
Luego visita [http://localhost:8000](http://localhost:8000) en tu navegador.
